### Resend: dashboard o API

- **Si uses el dashboard de Resend:** el `CONTACTES.md` no s'envia ni s'actualitza sol. Has de copiar aquest text/HTML al template de Resend o al cos del correu.
- **Si uses l'API:** el payload de codi és el que s'envia. El `.md` és només la teva còpia mestre.
- **No s'ha enviat res.** Açò és només documentació.

```js
import { Resend } from 'resend';

const resend = new Resend(process.env.RESEND_API_KEY);

await resend.emails.send({
  from: 'Miguel Gisbert <miguel.gisbert@agrovolt.es>',
  to: ['info@ijessolar.com'],
  replyTo: 'miguel.gisbert@agrovolt.es',
  subject: 'Piloto agrovoltaico en Alicante – colaboración con instalador',
  html: `...HTML de dalt...`,
  text: `...text de dalt...`,
});
```

> Si la teva versió del SDK no accepta `replyTo`, canvia-ho per `reply_to`.

### Regles per a Resend

- Envia **5-10 correus al dia**, individuals, no massius.
- Text pla o HTML simple, sense adjunts.
- Un o dos enllaços com a màxim.
- Personalitza la primera línia amb una referència real; si no, elimina-la.
- `reply_to` ha de ser `miguel.gisbert@agrovolt.es`, que ja tens a Thunderbird.
- Fes seguiment per telèfon al cap de 48-72 h.
- No activis **Enable receiving** a Resend: tu reps per DonDominio/Thunderbird. Serveix per rebre amb Resend i et demanaria MX; no ho necessites.
